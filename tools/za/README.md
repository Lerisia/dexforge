# The Z-A balls

The balls for the Z-A dex were picked on `ball-picker.html` (the page as published, with its data file and sprite sheets
inlined; 2026-10-05: 22 families the other dexes had never settled, the rest confirmed as drafted) and now live in the one
table every game shares, `src/Dexforge.Core/Data/balls.tsv` (see `tools/balls`). A gift keeps the Poké Ball the game hands
it in whatever is picked (Hoopa).
