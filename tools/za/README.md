# The Z-A balls

`src/Dexforge.Core/Data/za/balls.tsv` is the ball for each species and form of the Z-A dex: a draft taken from the Scarlet
picks (then Sword's, then the Ultra Sun save's), and the owner's own picks from the ball-picker page for the families Z-A
has that those dexes did not settle (2026-10-05: 22 families). `ball-picker.html` is the page as published, with its data
file and sprite sheets inlined; the page saves to the artifact's database and the picks are copied into the table by hand.
A gift keeps the Poké Ball the game hands it in whatever is picked (Hoopa).
